# 📚 Sistema de Gestión de Biblioteca - Refactorizado

Este es un sistema de gestión de biblioteca implementado en Java, que permite registrar libros y usuarios, gestionar préstamos y devoluciones, y realizar búsquedas por título o género.
El sistema ha sido refactorizado para mejorar su diseño, modularidad y mantenibilidad.

## 🧾 Características principales

- Registrar libros y usuarios.
- Buscar libros por título o género.
- Gestionar préstamos y devoluciones.
- Ver libros, usuarios y préstamos activos.
- Soporte para tipos de usuarios: Estudiante y Profesor.
- Interfaz modular con separación de responsabilidades.

## 🚀 Ejecución

1. Clona el repositorio o copia los archivos fuente.
2. Asegúrate de tener configurado un entorno Java.
3. Compila y ejecuta la clase principal (BibliotecaApp).
